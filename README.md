# LangChain-Resume-Analyzer-CSV-Generator-project

I built a **resume parsing web app** that takes a **ZIP file with multiple PDF resumes** and converts them into **clean, structured JSON output** that is easy to use for ATS systems.

🔹 **Key Features:**

* Upload and process multiple resumes at once using a ZIP file
* Extract text from PDFs using **PyMuPDF**
* Convert resume data into structured JSON using **TypedDict** (no Pydantic)
* Use **Google Gemini (LLM)** to intelligently extract information
* Simple and clean **Streamlit UI** to view and download JSON output

🔹 **Extracted Details:**

* Professional Summary
* Skills
* Total Years of Experience

This project helped me learn more about:
*GenAI workflows, prompt design, structured data extraction, LLM integration, and building apps with Streamlit*.
